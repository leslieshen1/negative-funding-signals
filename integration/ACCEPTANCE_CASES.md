# 服务器联调待验收用例

本表为测试计划，所有服务端结果尚待填写，不声称已通过。冻结模型、阈值、网格、原始业务时钟不变。

| ID | 输入 / 故障 | 预期可观察结果 | 当前状态 |
|---|---|---|---|
| S01 | 合成空批次 | hash一致，integration_test入库；不计真实预测，不发订单 | NOT_RUN |
| S02 | 原历史公开合成数量评分样例外包消息 | 冻结payload字节不变；历史/合成标记保留，不当实时输入 | NOT_RUN |
| S03 | 同ID同字节重复推送 | 一条业务事实，返回同一持久化确认，重复审计保留 | NOT_RUN |
| S04 | 同ID不同hash | 冲突隔离，不覆盖原记录，不推进连续游标 | NOT_RUN |
| S05 | 乱序 / 中间缺序 | 保存原序号，连续游标不跨缺口；补齐后恢复 | NOT_RUN |
| S06 | 已落盘但响应丢失、生产端重启 | 原ID和字节重传，无重复候选；待发送队列及序号可恢复 | NOT_RUN |
| S07 | HTTP成功但未落盘、接收端重启 | 不得假报DURABLY_STORED；重启后按真实持久化状态恢复 | NOT_RUN |
| S08 | 无候选 / 数据不足 / 本轮未运行 | 三种状态分别展示，不把缺失写成NO_CANDIDATES或零概率 | NOT_RUN |
| S09 | 原预测及时发出但网络送晚 | 原发出/服务器接收时间都保留；LATE_DELIVERY，不重置TTL | NOT_RUN |
| S10 | 首次预测生成已超网格5分钟 | 只留缺失/迟到状态，不补造真实预测 | NOT_RUN |
| S11 | 候选已过24h / 模型过期 | 审计可留存，暂停新候选使用；模型过期不重训 | NOT_RUN |
| S12 | 鉴权失败 / 请求被重放 | 拒绝并审计；无模型/业务内容改写，无密钥日志 | NOT_RUN |
| S13 | 非法JSON / payload哈希不符 / 版本不兼容 | 拒绝或隔离并返回原因；不自动填字段以继续 | NOT_RUN |
| S14 | 内网消费确认、处理失败与重启 | durable/consumed/strategy结果分别可查，消费游标持久化 | NOT_RUN |
| S15 | 行情/账户快照过期或回执迟到 | RC2拒绝过期新增；实际发生的晚到成交仍计账并复核 | NOT_RUN |
| S16 | 真实影子流接入 | 无下单权限、保持原网格/冷却/Top10，原台账计数不因传输重复而增加 | NOT_RUN |

每项需要执行版本、生产/消费端日志关联ID、源和目的时点、落盘后读回证据、结果和负责人。通过S01—S16也仅证明相应传输/消费路径，实盘策略仍需执行方E01—E14、账户事实及单独生产准入。
